---
name: LibreOffice PDF export latency
description: Why invoice PDF export feels slow and what the UI must do about it.
---

The invoice PDF is generated by writing the XLSX template then converting via headless
LibreOffice (`soffice --headless --convert-to pdf`). This conversion alone takes ~14s
and is expected/normal for the 15-tab workbook with embedded images.

**Why this matters:** With no progress feedback, a disabled export button during those
~14s reads as "broken" — an automated UI test flagged it as a failure even though the
backend was working correctly.

**How to apply:** Any trigger of the generate endpoint must show clear in-progress
feedback (spinner/"Generating..." label + toast), not just a silently disabled button.
Don't treat the slow conversion itself as a bug to "fix".
